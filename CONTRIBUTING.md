# Contributing

Contributions welcome via Pull Request.

1. Open an issue first for significant changes.
2. Chapters live in `chapters/NN-title.md`; the rights page in `front-matter/`.
3. Cite only sources you have read, in APA 7, in `chapters/99-references.md`.
4. Update `CHANGELOG.md` under `[Unreleased]`.
5. Text contributions are released under CC BY 4.0, code examples under MIT.
